What is FebMod?

FebMod is an addon-based mod.

Links:

  1. Discord
  2. Github

What mods do i need to use FebMod?

Using FebMod requires 2 mods:

  1. Fabric API
  2. Fabric Language Kotlin

How do I add an addon to FebMod?

The steps are really easy:

  1. Download FebMod and put it in your mods folder.
  2. Launch your game once, then close it. This creates the addons folder.
  3. Go to minecraft/config/febmod/addons.
  4. Drop your addon's JAR file into the addons folder.

How do i open FebMod GUI?
